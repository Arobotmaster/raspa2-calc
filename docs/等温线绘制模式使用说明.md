# RASPA 等温线绘制模式使用说明

该模式用于从 **RASPA2 / RASPA3** 的输出文件中批量提取吸附量数据，并绘制等温吸附曲线（Loading vs Pressure）。

---

## 适用的结果目录结构（重点）

工具会递归扫描 `--base-dir` 目录，自动识别常见输出结构：

> 若检测到 `mc*` 目录，会**优先按 mc 顺序**提取每个目录内的输出文件；否则才进入全目录递归扫描。

### 1) RASPA2 / RASPA3 高通量（典型 mc* 结构）

常见布局（示例）：

```
output_dir/
  mc1__done/
    Output/System_0/output_*.data    # RASPA2
  mc2__done/
    output/output_*.txt              # RASPA3
```

只要能在 `mc*` 目录下找到输出文件，即可提取压力与吸附量数据。

### 2) RASPA3（参数筛选 / 非 mc* 结构）

参数筛选模式的 RASPA3 输出通常是：

```
UQEFAZ_ASR_pacman/
  COV_12.8_P_1000_NAM_Xe__done/
    simulation.json
    output/output_298_1000.s0.txt
  COV_12.8_P_5000_NAM_Xe__done/
    simulation.json
    output/output_298_5000.s0.txt
  ...
```

- 关键点 1：**不需要 `mc*` 目录**，直接扫描 `output/output_*.txt`
- 关键点 2：框架名优先从每个任务目录的 `simulation.json` 解析（避免把 `output_298_1000...` 里的 `298` 误判为框架名）

## 使用方式

### 方式 A：交互式（推荐）

在你的工作目录（通常是 `$RASPA_WORK_DIR`）中运行：

```bash
raspa-calc
```

选择：

- `5` 等温线绘制模式

如果自动检测到结果目录，会列出候选项；否则可手动输入包含结果的目录路径。

支持批量选择多个结果目录：

- 多选示例：`1,3-5` / `all` / `全部`
- 若选择了“手动输入目录路径”，可一次输入多个路径（逗号分隔）

多目录模式下，会提示输出方式：

1. 每个结果目录下创建子目录
2. 统一输出到当前目录下，按目录名分子目录

### 方式 B：命令行（适合脚本化）

使用便捷命令：

```bash
raspa-plot-isotherm [目录] [选项]
```

示例（RASPA3 参数筛选结果，单位 mol/kg，压力单位 Pa，线性 x 轴）：

```bash
raspa-plot-isotherm /home/zjp/raspa2-calc/work/Xe/UQEFAZ_ASR_pacman \
  --type absolute --unit mol/kg --pressure-unit Pa --linearx \
  --outdir isotherms
```

示例（把压力换成 bar，并使用对数 x 轴）：

```bash
raspa-plot-isotherm /path/to/results --pressure-unit bar --logx
```

只绘制指定组分：

```bash
raspa-plot-isotherm /path/to/results --component Xe
```

## 常用参数说明

- `--base-dir` / 第一个位置参数：要扫描的结果目录（会递归扫描）
- `--component`：只画某个组分（不填则对所有组分分别作图）
- `--type`：`absolute`（绝对吸附）或 `excess`（超额吸附）
- `--unit`：`mol/kg`、`cm^3/g`、`mg/g`、`cm^3/cm^3`
- `--pressure-unit`：`Pa` 或 `bar`（工具会做 Pa↔bar 换算）
- `--logx`：对数压力坐标
- `--linearx`：强制线性压力坐标（用于覆盖 `--logx`）
- `--outdir`：输出目录（生成 png 与 csv）
- `--combine-all`：额外生成“同组分、多框架叠加对比图”
- `--include-unfinished`：包含未完成的模拟（默认跳过未完成）

---

## 输出文件

输出目录（`--outdir`）下会生成：

- `isotherm_<Framework>_<Component>_<type>_<unit>_<pressure_unit>.png`
- `isotherm_<Framework>_<Component>_<type>_<unit>_<pressure_unit>.csv`

CSV 为绘图用的数据点（Pressure, Loading）。

## 常见问题排查

### 1) 提示“找到 0 个 mc 目录”

- 对 RASPA3 参数筛选结构属于正常现象（因为本来就没有 `mc*`）。
- 确认你传入的目录下存在 `*/output/output_*.txt`，并且文件内容里有 `Simulation finished` 和 `Loadings`（否则可能被视为无有效数据点）。

### 2) 提示“未找到可用于绘制等温线的数据点”

常见原因：

- 模拟没跑完（输出里没有 `Simulation finished`），可尝试 `--include-unfinished`（但未完成时不一定有最终平均吸附量）
- 目录里只有作业脚本、`simulation.json`，没有 `output_*.txt/.data`
- 单位/吸附类型选错导致无法匹配（例如选择 `cm^3/g`，但输出里没有对应单位行）
