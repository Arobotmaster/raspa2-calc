# RASPA 参数筛选模式使用说明

## 概述

参数筛选模式支持对 simulation.input 中的**任意参数**进行组合测试，完全通过配置文件控制，无需交互输入。

## 特点

✅ **完全灵活** - 可测试任意参数组合
✅ **零交互** - 所有参数从配置文件读取
✅ **类型安全** - 自动识别数值/字符类型
✅ **智能命名** - 目录名反映实际参数
✅ **自动计算** - UnitCells自动计算
✅ **CSV集成** - 框架名和空隙率从CSV读取
✅ **RASPA3 资源复制** - 会把 `raspa3_json_dir` 中的力场/分子 JSON 复制到每个参数目录，并按 CIF/气体筛选 force_field

## 两个核心问题的实现

### 1. 框架名获取 ✅
**从CSV文件读取** - 与高通量模式一致

通过配置文件指定:
```yaml
calculation:
  csv_file_path: "/path/to/data.csv"
  framework_column: "coreid"  # 或 "refcode"
```

### 2. 空隙率获取 ✅
**从CSV文件读取** - 不再计算

通过配置文件指定:
```yaml
calculation:
  use_void_csv: true
  void_csv_file: "/path/to/void_data.csv"
  void_column: "VF"
```

## 完整配置示例

### config.yaml

```yaml
# 环境配置
environment:
  work_dir: "/path/to/work"
  raspa_dir: "/path/to/raspa"
  cif_dir: "/path/to/cif"

# 计算参数
calculation:
  # CSV文件路径 - 包含框架列表
  csv_file_path: "/path/to/structures.csv"

  # 框架名称列名
  framework_column: "coreid"

  # 模板文件路径
  template_path: "/path/to/simulation.input"
  # RASPA3: JSON 模板路径与 cif/json 目录
  raspa3_template_path: "/path/to/simulation.json"
  raspa3_cif_base_path: "/path/to/cif"
  raspa3_json_dir: "/path/to/raspa3json"

  # 是否从CSV读取空隙率
  use_void_csv: true

  # 空隙率CSV文件路径(可与框架CSV相同)
  void_csv_file: "/path/to/structures.csv"

  # 空隙率列名
  void_column: "VF"

# 参数筛选配置
parameter_screening:
  # 输出目录名
  output_directory: "param_screening_output"

  # 是否自动计算UnitCells
  auto_unit_cells: true

  # 参数筛选范围 - 支持任意参数
  parameters:
    # 数值型参数
    CutOffVDW: [12.0, 12.8, 14.0]
    CutOffChargeCharge: [12.0, 12.8, 14.0]
    NumberOfCycles: [10000, 20000]
    ExternalTemperature: [298, 323, 348]
    ExternalPressure: [0.0, 1e5]

    # 字符型参数
    ForceField: [huan5, UFF]
    ChargeMethod: [Ewald]
    # RASPA3: Name 会覆盖 Components[*].Name（多组分按顺序分配），Systems[0].Name 自动写入 CIF 绝对路径
    Name: [Xe, Kr]
```

### pyMSER 自动平衡（参数筛选）

- 默认复用 `calculation.mser` 配置；若需要单独设置，可在 `parameter_screening.mser` 覆盖
- 启用后生成的 job.sh 会在模拟完成后自动调用 `auto_mser_raspa2.py`/`auto_mser_raspa3.py` 判定平衡并续跑
- 平衡截断点使用 pyMSER 自带的 `t0`（默认判据）；`tail_rel_std`/`tail_window`/`min_t0_frac` 已弃用并会被忽略（避免因额外阈值导致任务被误判为失败）
- 生成的 simulation.input/simulation.json 会自动添加 JSON 重启所需的 `RestartFileName`（不使用二进制重启）
- 每个参数目录下有 `status.txt`：`pending`（已生成未运行）、`running`、`done`、`failed_simulate`、`failed_mser`

示例（针对参数筛选单独开启 pyMSER）：
```yaml
parameter_screening:
  mser:
    enable: true
    target_cycles: 2000
    add_cycles: 400
    max_iter: 20
    uncertainty: uSD
    conda_env: pymser
```

## 使用方法

1. **编辑配置文件** `/path/to/raspa2-calc/config.yaml`
2. **运行命令**:
   ```bash
   raspa-calc  # 选择模式 1
   ```

## CSV文件格式

### 框架和空隙率CSV示例

```csv

IRMOF-1,0.75,12.3,8.5
ZIF-8,0.50,10.2,3.4
UiO-66,0.45,8.9,6.1
```

- `coreid`: 框架名称列 (对应 `framework_column`)
- `VF`: 空隙率列 (对应 `void_column`)
- 其他列: 可选的结构参数

参数筛选任务结束后，可直接用 **等温线绘制模式** 批量画出吸附等温线：

- 交互式：`raspa-calc` → 选择 `5`
- 命令行：`raspa-plot-isotherm /path/to/结果目录 ...`

若你使用的是 **RASPA3**（`simulation.json`），通常每个参数目录下会有：


## 参数说明

### auto_unit_cells
- `true`: 根据CutOffVDW参数和CIF文件自动计算UnitCells
- `false`: 使用模板默认值

### use_void_csv
- `true`: 从CSV文件读取空隙率
- `false`: 从CIF文件计算空隙率(使用gemmi库)

### parameters
- 只需配置要测试的参数
- 参数名必须与simulation.input中完全一致(区分大小写)
- 程序会生成所有参数组合(笛卡尔积)

## 高级用法

### 只测试单个参数
```yaml
parameters:
  CutOffVDW: [12.0, 14.0, 16.0]  # 测试3个值
  NumberOfCycles: [20000]  # 保持固定
  ExternalTemperature: [298]  # 保持固定
```

### 测试多个分子
```yaml
parameters:
  MoleculeName: [CO2, CH4, N2, H2O]
  ExternalPressure: [1e5, 5e5, 1e6]
```

### 测试不同力场
```yaml
parameters:
  ForceField: [huan5, UFF, Dreiding]
  CutOffVDW: [12.0, 14.0]
```

## 常见问题

**Q: 框架名从哪里读取?**
A: 从CSV文件的指定列读取,通过`calculation.framework_column`配置

**Q: 空隙率从哪里获取?**
A: 从CSV文件读取(推荐),通过`calculation.use_void_csv`启用

**Q: UnitCells如何计算?**
A: 根据CutOffVDW参数和CIF文件自动计算

**Q: 如何查看将生成多少作业?**
A: 运行时会显示,例如: 3个参数×2个值 = 2×2×2 = 8个作业/框架

**Q: 如何添加新参数测试?**
A: 直接在`parameters`中添加,无需修改代码

**Q: CSV文件中没有某个框架的空隙率怎么办?**
A: 程序会警告,并尝试从CIF文件计算

## 注意事项

1. **配置文件同步**: 确保 `/path/to/raspa2-calc/.raspa_tools/config.yaml` 与主配置同步
2. **参数名大小写**: 参数名必须与 simulation.input 完全一致
3. **组合爆炸**: 注意参数组合数量,避免提交过多作业
4. **CIF文件**: 确保所有框架的CIF文件存在于指定目录
5. **CSV格式**: CSV文件必须包含框架列和空隙率列(如果启用use_void_csv)
