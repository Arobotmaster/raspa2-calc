# 数据提取模式使用说明（RASPA2 / RASPA3）

本工具在 `raspa-calc` 的 **模式 3：数据提取模式** 中使用，用于从计算结果中提取关键指标并输出为 `CSV/Excel`。

## 1. 入口

```bash
raspa-calc
# 选择 3：数据提取模式
```

## 2. 交互顺序（重要）

数据提取会按以下顺序交互：

1) 选择输出格式：Excel / CSV  
2) 输入要提取的目录路径（默认值随输出格式变化）  
3) 选择提取模式：高通量 / 普通  
4) 检测/选择 RASPA 版本（RASPA2 / RASPA3）  
5) 选择要提取的数据项（可自定义）  
6) 输出文件名（默认 `raspa_results.xlsx` 或 `raspa_results.csv`）

> 注意：输出文件默认保存在你运行 `raspa-calc` 的当前目录（通常是 `$RASPA_WORK_DIR`），不一定是你输入的“提取目录”。

## 3. 提取模式

### 3.1 高通量模式（按配置 CSV 顺序对齐）

用途：当你的计算任务来自配置里的筛选 CSV，希望结果 **严格按 CSV 顺序对齐**（缺失任务也保留占位行）。

- 会读取配置（优先 `base_path/.raspa_config.yaml`）：
  - `calculation.csv_file_path`
  - `calculation.framework_column`
- 运行时会输出 CSV 信息（路径/列名/行数），用于人工确认无误。
- 结果按 CSV 的行顺序输出，便于与原筛选表格一一对应。

### 3.2 普通模式（扫描 output 文件）

用途：不需要 CSV 对齐，仅希望从指定目录中 **自动遍历所有 output 输出文件** 并提取。

- RASPA3：遍历 `**/output/*.txt`（含 `*.s0.txt` 等）
- RASPA2：遍历常见 `Output/System_0/*.data` 等结构（以实际结果目录为准）

## 4. 输出格式与默认路径

- **Excel 模式**：默认提取路径来自配置推导（`environment.work_dir + calculation.output_directory`）。
- **CSV 模式**：默认提取路径为 **当前目录**（你运行 `raspa-calc` 的位置）。

### 4.1 配置优先级（重要）

数据提取会优先读取你输入的提取目录（`base_path`）下的 `.raspa_config.yaml`，例如：

```
/home/zjp/raspa2-calc/work/694Rn/.raspa_config.yaml
```

若该文件不存在，才会向上搜索项目内的 `config.yaml` / `.raspa_tools/config.yaml`，最后才回退到工具目录的系统级配置。

## 5. 可选提取项（当前菜单）

为了聚焦吸附相关数据，菜单保留/新增如下选项：

1. Absolute Adsorption（绝对吸附量）
2. Excess Adsorption（超额吸附量）
3. Adsorption Heat（吸附热）
4. Adsorption Heat at Infinite Dilution（无限稀释吸附热）
5. Henry Coefficient（亨利系数）
6. Rosenbluth Weight（Rosenbluth 权重）
7. pyMSER Average Adsorption（pyMSER 平均吸附量）

### 5.1 RASPA3：Widom / Henry / Rosenbluth

RASPA3 在无限稀释条件下常见输出（示例）：

```
Widom insertion Rosenbluth weight statistics:
Average Rosenbluth weight:    ...

Henry coefficient based on Rosenbluth weight:
Average Henry coefficient:    ... [mol/kg/Pa]
```

工具会对每个 `Component` 提取对应的 Henry / Rosenbluth 数值，并输出为列：

- `<component>_henry_coefficient`
- `<component>_rosenbluth_weight`

### 5.2 RASPA3：pyMSER 平衡统计（average + uncertainty）

当启用 pyMSER 自动平衡时，每个 `mc*` 目录会生成 `stats.json`（平衡后的均值与不确定度）。
选择 **pyMSER Average Adsorption** 后，会从 `stats.json` 提取每个气体的平均值与不确定度，列名示例：

- `N2_pymser_average_mol_per_kg`
- `N2_pymser_uncertainty_mol_per_kg`

说明：
- 单位来自 `stats.json` 的键（如 `N2_[mol/kg]`），无需在交互中额外选择单位。
- 仅对 RASPA3 生效；若目录下没有 `stats.json`，对应列为空。

## 6. 常见问题

### 6.1 “文件已保存但找不到”

输出文件默认保存在运行 `raspa-calc` 的当前目录；如果你在别的目录查找，会误以为没生成。

### 6.2 高通量对齐结果不对

- 确认你选择了“高通量模式（按配置CSV顺序对齐）”
- 确认运行时打印的 `csv_file_path/framework_column/CSV 行数` 与预期一致
